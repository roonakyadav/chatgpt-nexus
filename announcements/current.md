# Welcome to GPT-Nexus 2.0.1

We're excited to introduce **Night Sky**, our premium dark theme, along with significant visual improvements across the extension.

## What's New

### 🌙 Night Sky Theme
A beautiful, deep dark theme designed for long coding sessions. Perfect for developers who prefer a darker aesthetic.

### ✨ Visual Effects
New visual effects engine with:
- Smooth animations
- Glass morphism effects
- Subtle gradients
- Custom blur effects

### 🎨 Theme System
Completely redesigned theme system with:
- 5 premium themes
- Custom theme support
- Theme switching without reload
- Per-theme accent colors

## Improvements

- **Performance**: 40% faster rendering
- **Accessibility**: Better keyboard navigation
- **Mobile**: Improved responsive design
- **Stability**: Fixed 15+ reported bugs
