# Welcome to GPT-Nexus 1.7.5

We're excited to introduce the new announcement system with a premium modal design.

## What's New

### 📢 Announcement System
- Priority-based display (low, normal, high, critical)
- Premium modal design with hero images
- Type badges and icons
- Action buttons for external links and internal navigation
- Markdown-based authoring workflow

### 🎨 Modal Redesign
- Inspired by Discord, Notion, Arc Browser, Raycast
- Smooth animations (fade, slide, scale)
- Backdrop blur effect
- Responsive design
- Dark mode support

## Improvements

- **Developer Experience**: Markdown-based announcement authoring
- **Build Pipeline**: Automated announcement JSON generation
- **Release Pipeline**: Single-command release process
- **Validation**: Comprehensive checks before releasing

Thank you for using GPT-Nexus!
